# Benchmarking RSV-A EVEscape mutation prioritization against nirsevimab deep mutational scanning

A reproducible experimental benchmark for testing computational RSV-A F escape prioritization
against direct measurement.

**Status: the experimental half is complete and reproducible. The comparison itself is blocked on
one missing input** — see [Current status](#current-status).

---

## Scientific question

> How well do RSV-A F-protein EVEscape scores identify DMS-measured nirsevimab escape, among
> substitutions that retain F-mediated cell-entry function?

Two recent, independent results make this question answerable for the first time:

* **Simonich et al.** measured how nearly all amino-acid mutations in the RSV-A Long F ectodomain
  affect F-mediated cell entry and neutralization by the IgG and Fab forms of nirsevimab — but never
  compare their data to any evolutionary or computational escape model.
* **Zhou / Henschel et al.** apply subtype-specific EVEscape models to RSV-A and RSV-B F for genomic
  surveillance in the UAE — and state explicitly that *"the escape analyses were computational and
  not complemented here by functional neutralization or virological assays."*

Putting the two together tests a computational mutation prioritization against direct experimental
measurement, on the specific protein and antibody where it matters clinically.

## The benchmark table

`data/dms_nirsevimab_functional.csv` — **4,276 rows**, one per amino-acid substitution.

| Column | Meaning |
|---|---|
| `mutation` | `<wildtype><site><mutant>`, e.g. `K209N` |
| `site` | Standard RSV F numbering, position 1 = N-terminal Met. Range 26–529 |
| `wildtype`, `mutant` | Amino acids, RSV-A Long background |
| `Nirsevimab-Fab escape` | Positive = decreased neutralization by nirsevimab Fab |
| `Nirsevimab-IgG escape` | Positive = decreased neutralization by nirsevimab IgG |
| `cell entry` | log2 cell entry relative to unmutated Long F; negative = impaired |
| `region` | Broadly defined antigenic region; literal `"none"` outside the six regions |

Every row satisfies: real substitution (not a wildtype-identity row) · unique mutation ID ·
cell entry measured · `cell entry > -2.5` · at least one nirsevimab measurement present.

### Three things to know before using it

1. **`> -2.5` is the source paper's own published criterion**, not a choice made here. Simonich et al.
   state it verbatim: *"mutations that retain at least some moderate level of cell entry (a cell
   entry effect > -2.5 in our measurements)"*. It was fixed before any EVEscape score was inspected.

2. **A missing escape value means "filtered as imprecise", not "not measured".** The upstream
   pipeline drops estimates failing `times_seen >= 2`, `frac_models >= 0.67`, or a per-antibody
   `escape_std` cutoff. Notebook 01 §3 proves this by reconstructing all three columns from the
   per-assay files at 100% agreement. The benchmark population is therefore *non-randomly censored* —
   noisy estimates are preferentially removed. Missing values are kept as `NaN` and must never be
   imputed to 0: a dropped noisy measurement is not evidence of "no escape".
   (299 Fab and 32 IgG values are missing; no row is missing both.)

3. **These are experimentally measured mutation effects, not "ground truth".** `cell entry` measures
   F-mediated cell entry in a pseudovirus assay. It is not viral fitness, viability, or
   transmissibility — the source paper is explicit that *"cell entry is only one of several F
   properties that contribute to transmissibility"*.

## Reference compatibility — the critical check, and it passes

The DMS uses RSV-A **Long** (isolated in the 1950s); the UAE EVEscape analysis is referenced against
**KX858757.1** (2013). Whether `DMS K209N` and `EVEscape K209N` mean the same substitution had to be
established, not assumed.

### Where each reference is documented

| Side | Reference | Documented in |
|---|---|---|
| EVEscape | KX858757.1 | UAE preprint, Methods, *"RSV F-gene sequencing and mutation analysis"* (p. 6): *"reference isolates RSV A-NLD-13-005275 (GenBank accession KX858757.1)…"* — and in code at `rsv_global/.../escape_utils.py`: `REFERENCE_ACCESSION_BY_SUBTYPE = {"RSVA_F": "KX858757.1", …}` |
| DMS | RSV-A Long | Simonich et al., Results, *"Experimental measurements of functional constraint on all F mutations"*: *"the lab-adapted subtype A strain of RSV termed 'Long'"*. No GenBank accession is given in the paper; the sequence used here is record 1 (`RSV_Long_F`) of `RSV_Long_F_DMS/data/RSV_F_seqs/RSV-A_with_ref.fasta`, cross-checked against the pipeline's own construct sequence `results/gene_sequence/protein.fasta` |

### Result

| Check | Result |
|---|---|
| Protein length | 574 aa on both sides |
| Insertions / deletions | **none** — gapless 1:1 alignment |
| Numbering offset | **none** — DMS `site` ≡ EVEscape `i` in the same 1..574 frame |
| Identity over sites 26–529 | 98.41% (496 / 504) |
| Wildtype disagreements in window | **8**: sites 80, 101, 105, 124, 213, 276, 384, 515 |
| Benchmark rows dropped | **137 of 4,276 (3.20%)** |
| **Expected merge coverage** | **4,139 / 4,276 = 96.80%** |

Both sides count from Met1 of the full-length 574-residue F. On the DMS side this is stated
explicitly (`RSV_Long_F_DMS/data/README.md`: *"the standard RSV F numbering scheme (which starts
with 1 at N-terminal Met)"*). On the EVEscape side it follows from the code: `compute_evescape_scores.py`
indexes the KX858757.1 CDS as `cds[(pos-1)*3 : pos*3]`, and `cds[0:3] = ATG`.

Two independent corroborations, neither relying on the alignment:

* the wildtype residue agrees at 496 of 504 positions — under a numbering offset the agreement would
  be at chance level (~5%), not 98.4%;
* the DMS antigenic-region annotations and the coordinate ranges hard-coded in
  `rsv_global/.../escape_utils.py` agree at 450 / 456 sites (98.7%).

`outputs/reference_compatibility_by_site.csv` gives the full per-position table
(`site, dms_wt, evescape_wt, agree`) so every position can be checked directly.

**Known coverage gap:** site 213 is one of the 8 disagreement sites and lies *inside* the nirsevimab
epitope (201–216), so all 15 site-213 substitutions are lost. No dropped row reaches the
strong-escape tail (Fab > 1.0, n = 98), so top-k enrichment is unaffected — but the gap is named
rather than absorbed into a percentage.

### What is needed

`rsv_global` ships the EVEscape scoring scripts but no production data; its
`toy_examples/evescape_minimal/` contains a 3-mutation worked example.

**Preferred:** the final RSV-A per-mutation EVEscape table with

```
mutation, wt, i, mut, evescape, evescape_composite, evescape_percentile
```

for all 10,906 non-reference substitutions (574 positions × 19). `merge_dms_evescape()` in notebook
02 consumes exactly this schema.

**Fallback:** RSV-A EVE evolutionary indices across training seeds + the RSV-A WCN table +
`inputs/references_RSV_AB/F_prot.ref.fasta`. Of these, only the WCN table and reference FASTA are
reconstructible from public information (5UDC and KX858757.1 are public; `compute_wcn.py` is in the
repository). The EVE evolutionary indices are not reproducible without retraining EVE on the
12,108-sequence RSV-A alignment — which would no longer be testing the published model.

## Scope and limitations

* **RSV-A only.** The comprehensive DMS exists only for RSV-A Long. This is an RSV-A
  proof-of-concept benchmark of the model, **not** an experimental validation of the UAE study's
  findings — that study's escape-burden signal is in RSV-B, and its recurrent RSV-A substitutions
  rank low on the single-mutation EVEscape scale (L381F, the highest among them, at the 8.7th
  percentile). Extending to RSV-B would require both the RSV-B EVEscape table *and* a comprehensive
  RSV-B DMS, which does not exist.
* **EVEscape is antibody-agnostic; the DMS endpoint is nirsevimab-specific.** Only 8.6% of benchmark
  rows lie in the nirsevimab epitope, yet 93 of the 98 mutations with Fab escape > 1.0 are there.
  A modest global rank correlation is the *expected* outcome and is interpretable as such; see
  `ANALYSIS_PLAN.md`.
* **The genetic backgrounds differ.** Even where the wildtype residue agrees, the DMS measures in the
  Long background while EVEscape scores in the KX858757.1 background; the two proteins differ at 11
  positions overall. Simonich et al. demonstrate background dependence directly (S211R has opposite
  signs in the Long and B1 backgrounds), though that comparison spans ~90% identity whereas
  Long ↔ KX858757.1 are 98.4% identical.
* **Cell entry is not fitness.** See point 3 above.

## Reproducing

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Notebook 02 runs as-is. Notebook 01 additionally needs the upstream DMS repo:
git clone https://github.com/dms-vep/RSV_Long_F_DMS.git
git -C RSV_Long_F_DMS checkout e01679cf2d0cc0a1038e46eb4a64f42e711ff838

jupyter lab notebooks/
```

Notebook 01 asserts the upstream commit hash and hash-verifies its output against the shipped table,
so a silent upstream change fails loudly rather than quietly altering the numbers. No step is
stochastic; no random seed affects any reported value. Files in `outputs/` are regenerated by the
notebooks.
